# Streamora Utility

Public installers and signed update feeds for Streamora Utility on macOS Monterey 12 or later.

Download the latest release: choose `mac-x64.dmg` for Intel or `mac-arm64.dmg` for Apple Silicon. Drag the app to Applications and pair it with a code from Streamora Workers. Personal builds may require Open Anyway on first launch.

After installing the updater-enabled version, use **Check for Updates** in the app. No GitHub login is needed. Archives and feeds are signed; the private signing key is never distributed.

The application source repository is maintained separately. Bundled open-source licenses and corresponding FFmpeg/x264 sources are included in the app.
